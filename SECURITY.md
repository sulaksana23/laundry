# Pelaporan Keamanan

Jangan membuat issue publik untuk credential bocor, kelemahan autentikasi, kebocoran data pelanggan, atau celah akses cabang.

Laporkan secara privat kepada pemilik repository melalui kanal keamanan GitHub. Sertakan versi/commit terdampak, langkah reproduksi yang aman, dan dampak yang terlihat. Jangan menyertakan data pelanggan nyata atau secret dalam laporan.

Sebelum rilis produksi, wajib memasang autentikasi, otorisasi server-side, isolasi tenant/cabang, validasi input, pembatasan percobaan, audit log, manajemen secret, backup, serta kebijakan retensi data.
