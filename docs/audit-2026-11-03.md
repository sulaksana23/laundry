# Audit LaundryOS — 3 November 2026

> Dokumen ini adalah snapshot sebelum pembaruan operasional 5 November 2026. Daftar pekerjaan lama di bagian akhir sudah tidak mewakili status terbaru; gunakan [roadmap.md](roadmap.md) dan [security.md](security.md) untuk status terkini.

## Cakupan

Review mencakup halaman dan aksi workspace, autentikasi/sesi, API pesanan dan layanan, repository PostgreSQL, operasi pelanggan/keuangan/persediaan/laporan, migrasi, seeder, serta workflow CI.

## Temuan yang diperbaiki

- Daftar pesanan sebelumnya hanya memuat 100 data awal; pencarian dan filter berjalan pada data yang sudah diunduh. Kini pencarian, filter status, dan pagination 25 baris meminta data langsung dari API cabang. KPI pesanan menggunakan agregasi semua data cabang.
- ID pesanan memakai akhiran acak 16-bit yang berisiko bentrok saat volume meningkat. Akhiran diperpanjang menjadi 48-bit.
- Riwayat status awal memakai aktor placeholder. Sekarang aktor diambil dari pengguna pada sesi server.
- Tanggal pengeluaran yang bentuknya cocok tetapi tidak valid, seperti tanggal 31 Februari, kini ditolak sebelum query database.
- Ringkasan aktivitas pelanggan, kas harian/bulanan, laporan, ekspor, dan tampilan tanggal mengikuti zona waktu default cabang (Asia/Makassar). Grafik mingguan menghitung pesanan masuk, termasuk pesanan yang belum dibayar.
- Workflow sebelumnya berhenti pada lint karena pemanggilan waktu saat render dan pembaruan state dalam effect; pemanggilan state dipindah ke callback browser dan penggunaan waktu server diberi pengecualian terarah. Import tidak terpakai dan navigasi internal berbasis location juga dibersihkan.

## Batas audit

Audit kode tidak membuktikan aplikasi bebas bug. Workflow CI menjalankan lint, typecheck, dan build; repository belum memiliki suite unit/integration test untuk query Neon. Setelah commit, status workflow harus dilihat untuk memastikan ketiganya lolos.

Sejak snapshot audit ini, akses peran/cabang, rate limit bersama, audit utama, ledger stok, refund, backup/restore, dan data dashboard telah dikembangkan. Reset kata sandi, notifikasi otomatis, dan sebagian kebijakan berat/refund/jam usaha masih belum ditetapkan.
